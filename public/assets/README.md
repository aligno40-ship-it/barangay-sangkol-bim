# Barangay Asset Storage Directory

This directory stores uploaded and static assets for the Barangay Sangkol Information Management System (BIMS):

- `logos/` : Official Barangay Sangkol seal, Municipal/City logos, Republic seal, and watermarks.
- `profiles/` : Resident profile photos, official portraits, and staff avatars.
- `signatures/` : Scanned digital signatures of the Punong Barangay, Secretary, and issuing officers.
- `documents/` : Uploaded verification attachments, templates, and certificates.

All files placed here can be referenced in the app directly using `/assets/...` (e.g. `/assets/logos/barangay_seal.png`, `/assets/profiles/sample.jpg`).
